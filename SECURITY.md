# Security Policy

## Supported Versions
| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |

## Reporting a Vulnerability

Please **do not** open a public issue.

Email **joel.bathula@hansaitechnosoft.com** with:
- Description, impact, and reproduction steps
- Affected version / commit

We aim to respond within 72 hours and will coordinate a fix and disclosure timeline.

## Scope
This policy covers the code in this repo and the published `parity-kit` npm package. The comparison targets (your baseline/current URLs) are out of scope.
