# Changelog

All notable changes to **parity-kit** will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-30
### Added
- Initial public release as `parity-kit` (renamed from `web-parity-kit`)
- CLI: `parity-kit`, `parity`, legacy alias `web-parity-kit`
- Pixel-perfect diff via Pixelmatch + pngjs
- Computed CSS delta inspector (h1/h2/p/button/nav/container)
- Animation & micro-interaction audit (transitions, keyframes)
- SEO & schema validation (title, meta, OG, Twitter, canonical, JSON-LD)
- Zero-flake preprocessors: freeze animations, hide caret, hide scrollbars, waitForFonts, img.decode()
- Sitemap + crawler auto-discovery
- Interactive HTML dashboard: side-by-side, swipe scrubber, onion-skin, CSS inspector, console/network health
- Programmatic API `runParityScan()` + TypeScript types
- GitHub Actions PR comment workflow
